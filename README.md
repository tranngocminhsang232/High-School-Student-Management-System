# High School Student Management System

## 1. Giới thiệu

Hệ thống Quản lý Học sinh THPT hỗ trợ quản lý hồ sơ học sinh, phân lớp, phân công giáo viên, quản lý điểm số, chuyên cần, hạnh kiểm, báo cáo thống kê và thông báo dành cho phụ huynh.
